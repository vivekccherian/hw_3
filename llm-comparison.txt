Comparatively, the models.py I created versus the LLM's robot-models is simpler in the sense that it possesses six small table used to store names/emails directly, use FileField for photos, and protect against cheating with unique qr identifiers and timestamps. In comparison, the LLM is much more complete as it links Django's built-in User model, stores start/end times for classes, decodes QR values + stores them, and includes many helper methods to check arrival of photos. There is a tradeoff between time needed to set up, but it is better for analytics and to prevent cheating. My models would need to be built upon.
